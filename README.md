upAPI is an API marketplace platform that provides a single API key and gateway to access over 60 production APIs across categories such as media, finance, social media, and more. It offers weighted‑unit billing, per‑operation pricing, and supports multiple programming languages. The service includes a developer portal, documentation, pricing, and support, and is hosted at upapi.io with its API endpoint at api.upapi.io.

**Areas:** API Marketplace · Developer Tools · Data · Automation · Integration

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for upapi-io: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
